## 已安装电脑如何更新

解压并将全部更新文件合并到原 **C:\pro**，替换同名代码，**保留原outlines、soft、模型和Python环境**。不能仅替换主程序，新增窗口模块和启动入口都需复制。常规已安装环境无需新增pip依赖。

本仓库是更新代码，不包含大型OCR模型或原离线安装包。新电脑部署见[离线说明](OFFLINE_GUIDE.md)。

## 新的使用入口

1. 双击 **打开大纲管理.bat**（英文同名入口 `open_outline_manager.bat`）。
2. 窗口会读取已有车辆目录，显示“已导入”。已完成的A/B/C车无需重导，只选择需要补充的D/E/F。
3. 点击 **批量选择大纲文件**，可按Ctrl/Shift一次选多份。核对每行车辆与文件后，点击 **开始导入勾选项**。
4. 成功项自动取消勾选，失败和未完成项保留。可选择当前文件完成后停止；重新打开会恢复队列。
5. 导入完成后，照常使用 **run_preview.bat → 核对CSV → run_export.bat** 处理混合车辆扫描记录。

文件名可明确判断车辆时只做预填，不能判断的车辆留空；开始前必须核对对应关系。没有通过验证的行不会盲目按文件顺序分配车辆。

旧 `import_vehicle_outline.bat` 也会转到新窗口。备用旧命令行入口保存在 `import_vehicle_outline_cli.bat`。

## 原有功能保留

完整PDF大纲优先整理编号书签或目录，必要时整理正文中的试验标题候选；扫描使用本地PaddleOCR。每车独立CSV，完整车号专用目录优先于字母类别目录。

逐页识别车号后，仅在该车大纲中匹配科目。缺车、缺目录或科目歧义时标记待匹配，不跨车套号。目录核对表保留来源页码和提取方式。

文件名：`大纲序号-实验名称-完整车号-日期-地点-V011.pdf`。

双击 `make_demo_data.bat` 可生成A～F完整示例大纲和混合车辆扫描记录。示例标记保留，真实目录逐车替换后只移除该车标记。[六车测试与完整PDF操作说明](MULTI_VEHICLE_GUIDE.md)

## 启动与日志

请在原程序目录运行 **C:\pro\打开大纲管理.bat**。界面显示当前工作目录，便于确认没有误开下载目录中的另一份软件。

启动检查：`logs/outline_manager_startup.log`。窗口/导入错误：`logs/outline_manager.log`。已有目录是磁盘CSV，旧窗口消失不会自动删除已保存文件。

窗口使用Python自带tkinter；如缺tcl/tk，原Python安装程序的Modify可补装，无需pip安装tkinter。重复启动会尝试显示已有窗口。目录写入改为完成后替换，避免中断损坏旧目录。
