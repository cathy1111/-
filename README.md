# 试验记录归档软件 v1.4：完整PDF大纲整理与分车辆命名

支持A～F车各自维护试验大纲，逐页识别混合车辆扫描记录，选择对应车辆的大纲科目编号并统一命名。也可按A204等完整车号建立专用大纲。

[下载软件更新包](https://github.com/cathy1111/-/archive/refs/heads/fix/offline-windows.zip) · [完整操作说明](MULTI_VEHICLE_GUIDE.md)

## 更新已有软件

解压并将全部更新文件合并到原 **C:\pro**，替换同名文件，**保留原soft中的模型、Python和依赖**。不要只替换主程序；新增模块和启动脚本也必须一起复制。已有环境无需重装，启动窗口版本为 **v1.4.0**。

本仓库仍是软件源码/补丁，不含大型OCR模型和安装包。新电脑离线部署见[离线说明](OFFLINE_GUIDE.md)。运行全程使用本地文件和PaddleOCR，不需要API或云端大服务器。

## 没有真实资料，先生成六车示例

1. 双击 **make_demo_data.bat**，在 `examples/multi_vehicle` 生成六份完整示例大纲PDF（含封面、目录、正文）及一份六车混合扫描记录PDF。
2. 双击 **import_vehicle_outline.bat**，输入A，拖入 `full_outlines/A_outline.pdf`；按相同步骤导入B～F。
3. 运行 **run_preview.bat**，拖入 `mixed_vehicle_records_scan.pdf`，核对清单。
4. 运行 **run_export.bat**，拖入同一PDF，导出带序号的单页PDF。

示例使同一“加速性能试验”在A～F车分别对应1.3～6.3，用于检查跨车套号。示例目录输出带 **示例-**，不代表实际大纲编号。

## 后续用真实资料

使用 **import_vehicle_outline.bat**，分别绑定A～F车或完整车号，并拖入该车真实完整大纲PDF；也支持Excel/CSV/Word/TXT。软件生成 `outlines/vehicle_A.csv` 等独立目录。

完整PDF优先读取编号书签、目录；无可用目录时整理正文中的试验标题候选。扫描页使用本地OCR。提取核对表保留来源页码、提取方式和冲突项，不能确认的序号不会编造。

核对各车目录后，一次输入含多个车的原始记录PDF，逐页匹配。预览清单显示“大纲车辆、大纲来源、大纲序号、匹配状态”。

正式命名：

`大纲序号-实验名称-完整车号-日期-地点-V011.pdf`

缺车号、缺对应大纲、同名歧义或找不到科目时标记待匹配，不套用别的车辆大纲。完整车号专用目录优先于字母类别目录。

## 核对和兼容

导出采用已核对CSV，不重新OCR覆盖修改；核验原PDF和车辆大纲库的对应关系。车辆跨类别修改时需同时核对其大纲编号。相似名称只作建议，不猜序号。

v1.3共用目录入口 `import_outline.bat` 仍可用；存在分车辆目录时默认优先按车选择，不自动回退到共用目录。

真实目录替换只影响对应车辆的示例标记，其他示例车仍保留标记。生成的示例记录是打印文字栅格化PDF，不能代表所有手写体的准确率。
